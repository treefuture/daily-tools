# 🖱 鼠标手势控制 - Chrome 扩展

通过鼠标右键手势控制浏览器操作。

## 手势列表

| 手势 | 路径                      | 动作                       |
| ---- | ------------------------- | -------------------------- |
| ◀    | ← 左滑                    | 后退                       |
| ▶    | → 右滑                    | 前进                       |
| ⇧    | ↑ 上滑                    | 回到页面顶部（平滑滚动）   |
| ⇩    | ↓ 下滑                    | 滚动到页面底部（平滑滚动） |
| ➕   | →↑ 右滑再上滑（L 形）     | 新建标签页                 |
| ✕    | ↙↘ 斜左再斜右（V 形锐角） | 关闭当前标签页             |
| ↩    | ↘↙ 斜右再斜左（V 形锐角） | 恢复关闭的标签页           |

**规则：**

- 右键单击（不拖动）—— 正常弹出上下文菜单
- 拖动超过 30px 后进入手势模式
- 只有完全匹配预定义模式的手势才生效，多余动作取消
- 回到顶部/底部使用平滑滚动

## 安装

1. 打开 Chrome，进入 `chrome://extensions`
2. 开启"开发者模式"（右上角）
3. 点击"加载已解压的扩展程序"
4. 选择本项目根目录

### 生成图标

运行 `icons/generate-icons.bat`（Windows）生成扩展图标 PNG 文件，
或者手动创建 16×16、48×48、128×128 的 PNG 放入 `icons/` 目录。

## 设置

在扩展管理页点击"详情"→"扩展选项"，或在 `chrome://extensions` 中点击插件详情页打开设置：

- 轨迹样式：轨迹线 / 方向箭头 / 两者
- 颜色：轨迹颜色、箭头颜色
- 透明度 / 粗细
- 是否显示动作名称
- 最小拖动距离（灵敏度）

```
│   └── options.js            # 设置页面逻辑

```
